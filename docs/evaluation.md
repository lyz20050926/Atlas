# Evaluation methodology

Run:

```bash
python -m scripts.run_evaluation
```

Use the installed project virtual-environment Python; install `requirements-dev.txt` before running the release gate (or use `uv sync --frozen`). The bundled evaluation set contains 12 undergraduate profiles across embodied intelligence,
autonomous robotics and human-robot ethics. The deterministic run uses dated, clearly labelled
Google Books and Open Library snapshots selected per topic, so tests do not depend on network
availability and do not reuse one book set for unrelated learning goals.

Metrics cover identity verification, hard time/role constraints, Pydantic output validation,
replanning, source attribution, bounded-loop termination, semantic relevance gating and transparent
fit score. Results are written to `evaluation_results/latest.json` rather than copied by hand.

## Topic 4 digital-agent scorecard

The generated reports now expose the six performance categories named in the hackathon training
material. The scope is deliberately visible so deterministic evidence cannot be mistaken for a live
model claim.

| Training metric | Deterministic report | Live report | Interpretation |
| --- | --- | --- | --- |
| Schema validation pass rate | Typed final-output construction | Bedrock tool output that validates on its first attempt | Retries remain visible rather than being hidden inside a final pass. |
| Tool-call success rate | Fixture-backed search adapter returned usable candidates | Share of planned Google Books/Open Library operations returning at least one usable record | Cache hits, network calls, empty results and failures are also recorded. |
| Task completion rate | Three verified, relevant stages satisfying hard constraints | Same end-to-end criterion for each live case | A merely plausible answer is not counted as completion. |
| Token cost per run | Exactly zero model tokens and zero model cost | Input, output, cache-read and cache-write tokens per task | Convert to currency with current account/model prices or the AWS billing export; no stale price is hard-coded. |
| Loop discipline | Average search passes, three-pass cap and cap-hit rate | The same metrics on live cases | Both convergence and repeated cap exhaustion are visible. |
| Answer fidelity | Transparent semantic-relevance proxy | Relevance proxy plus explicit human-review status | Neither proxy is presented as a reviewed ground-truth score. |

The rule-based semantic gate is not a blind human semantic-quality claim. A separate live runner calls
Google Books, Open Library and the configured Bedrock model only after the operator acknowledges cost:

```bash
python -m scripts.run_live_evaluation --confirm-live-cost
```

Never merge the deterministic, live-integration and future human-review scores into one number.
Use the blind protocol in `docs/human_evaluation_protocol.md` before making a human-validated answer
fidelity or learning-benefit claim.

## Latest reproducible run

The latest deterministic report is regenerated by the release preflight. It covers 12 cases and
stores both the product-specific metrics and the six Topic 4 categories in machine-readable JSON.
Model calls, model tokens and model cost are `0` because this run deliberately excludes Bedrock.

The included historical live smoke report completed one English and one Chinese path. Its timestamp
does not establish acceptance of later source changes. An optional fresh live evaluation can populate
first-attempt schema validity, source-tool outcomes, task completion and loop-discipline fields for the
current source, using the operator's authorised credentials. That run is billable and must remain
separate from deterministic and human-review results. Launching `python launch.py` in default demo
mode does not perform this live evaluation.

## Release gate

Run all free checks and generate `evaluation_results/preflight_latest.json` with:

```bash
python -m scripts.preflight
```

The gate covers Ruff, Pytest, bytecode compilation, secret-shaped value scanning and the deterministic
evaluation. It deliberately excludes network calls and Bedrock cost.
